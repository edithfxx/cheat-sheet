# 📚 速查表 Cheatsheet

個人用的「程式碼速查表」單頁網頁。把常用的程式碼片段、指令、語法對照、觀念筆記分類存起來，需要時**三秒內搜尋、複製、編輯**。

純前端、免安裝、免打包 —— 一個資料夾用 Live Server 打開就能跑。

---

## ✨ 特色

- 🔍 **即時搜尋**：打關鍵字立刻篩選，且會跨所有分類搜尋；支援 `Ctrl + K` 快捷鍵
- 📋 **一鍵複製**：整段、逐行、逐列、逐區塊都能複製
- 🗂 **5 種卡片類型**：程式碼、逐行指令、對照表、多區塊、純筆記
- ✏️ **新增 / 編輯 / 刪除**：直接在畫面操作，不用改檔
- 💾 **匯出 / 匯入 JSON**：方便備份與換電腦
- 🎨 **米色護眼配色** + 響應式版面（桌機 4 欄，手機自動縮成 1 欄）

---

## 🚀 如何開始（請務必看這段）

因為程式用 `fetch()` 讀取資料檔，**不能直接雙擊 `index.html`**（會出現空白畫面或載入失敗），必須用本機伺服器開啟。

### 推薦：VSCode + Live Server

1. 用 [VSCode](https://code.visualstudio.com/) 打開**整個資料夾**
2. 安裝擴充套件 **Live Server**（在擴充套件市集搜尋安裝）
3. 在 `index.html` 上按右鍵 →「**Open with Live Server**」
4. 瀏覽器會自動打開，看到卡片畫面就成功了 🎉

> 第一次打開會載入內建的範例卡片（在「操作說明」分類），可以照著玩、之後再換成自己的內容。

---

## 📖 操作說明

| 功能 | 怎麼用 |
|---|---|
| 🔍 **搜尋** | 上方搜尋框打關鍵字（標題、標籤、內容都會找），會**跨所有分類**搜尋；按 `Ctrl + K` 快速跳到搜尋框 |
| 📂 **切換分類** | 點上方分類膠囊（HTML、CSS…）只看該分類 |
| 🗃 **篩子分類** | 點**右下角圓形按鈕**，選擇目前分類底下的子分類 |
| 📋 **複製內容** | 點卡片右上或每行右側的複製鈕（筆記類 note 沒有複製鈕，純閱讀） |
| 👁 **看完整內容** | 卡片只顯示前幾行，**點一下卡片**會跳出完整視窗，按 `Esc` 關閉 |
| ➕ **新增卡片** | 右上「新增」按鈕，選類型、填內容、儲存 |
| ✏️ **編輯 / 刪除** | 卡片上的**鉛筆圖示**可編輯、**垃圾桶圖示**刪除 |

## 💾 資料儲存與備份

- 你的卡片資料存在**瀏覽器的 localStorage**（不是存在檔案）。
- 新增 / 編輯 / 刪除都會**自動存進瀏覽器**，不用手動按儲存。

> ⚠️ **重要**：清除瀏覽器資料 / 換瀏覽器 / 換電腦，localStorage 就會清空。請定期備份！

### 備份與換電腦流程

1. 點右上**齒輪設定** →「**匯出 data.json**」，會下載一個 `data.json`
2. 把這個檔案放進專案的 `data/update/` 資料夾，**覆蓋**舊的 `data.json`
3. 換電腦時，新電腦第一次打開就會自動讀這個檔，免手動匯入

> 同一台用過的電腦若要強制重讀 `data.json`，按設定裡的「**重置為 data.json**」（注意：這會清掉還沒匯出的變更）。

## 🗂 5 種卡片類型

| 類型 | 用途 | 範例 |
|---|---|---|
| `code` | 一段程式碼 | Vue 元件模板、function |
| `lines` | 逐行指令（每行可單獨複製） | 終端機指令 `npm install` |
| `table` | 兩欄對照表 | 標籤 ↔ 說明 |
| `sections` | 多個可摺疊區塊 | 同主題的多種寫法 |
| `note` | 純筆記重點（無複製鈕） | 觀念整理、注意事項 |

每種類型在「操作說明」分類都有對應的「範例-」卡片可以參考。

## 📁 檔案結構

```
myChatSheet/
├─ index.html            # 主頁面（HTML 結構 + 載入三個 script）
├─ css/
│   └─ style.css         # 全部樣式
├─ script/
│   ├─ app.js            # 全部 Vue 邏輯
│   └─ config.js         # 分類、資料檔路徑等設定
└─ data/
    └─ update/
        └─ data.json     # 卡片資料（種子來源）
```

## ❓ 常見問題

**Q：雙擊 index.html 打開是空白 / 載入失敗？**
A：不能直接雙擊，請用 Live Server 開啟（見上方「如何開始」）。

**Q：我的卡片不見了？**

> [!CAUTION]
> ### ⚠️ 資料存在瀏覽器，清除瀏覽器資料會消失！
> **從備份的 `data.json` 還原：放進 `data/update/` 後，按設定的「重置為 data.json」。**

**Q：可以加新分類嗎？**
A：可以，編輯 `script/config.js` 裡的 `CATEGORIES` 陣列加上分類名稱即可。

## 🛠 技術棧

- **Vue 3**（CDN global build，免 build、免 npm）
- 原生 CSS + CSS variables
- 資料儲存：瀏覽器 localStorage
- 開發工具：VSCode + Live Server

> 刻意不使用 React / Vite / TypeScript 等需要打包的工具，目標是「一個資料夾用瀏覽器打開就能用」。
