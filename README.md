# 📚 課堂觀念與程式碼速查表 Cheatsheet

本專案為個人專用的「程式碼速查表」單頁網頁。將常用的程式碼片段、指令、語法對照與觀念筆記分類封存，需要時可在 **三秒內搜尋、複製與編輯**。

純前端、免安裝、免打包 —— 一個資料夾用 Live Server 打開即可執行。

## ✨ 核心特色

- 🔍 **即時搜尋**：輸入關鍵字立刻跨分類篩選；支援 `Ctrl + K` 快捷鍵。
- 📋 **一鍵複製**：整段、逐行、逐列、逐區塊皆可一鍵複製。
- 🗂 **5 種卡片類型**：程式碼、逐行指令、對照表、多區塊、純筆記，滿足不同場景。
- ✏️ **視覺化操作**：直接在瀏覽器畫面上新增、編輯、刪除，無需手動修改程式碼。
- 💾 **資料導入導出**：支援匯出/匯入 JSON 檔案，方便備份或跨裝置同步。
- 🎨 **舒適視覺**：採用米色護眼配色，並支援響應式版面（行動裝置自動單欄優化）。

## 🚀 如何開始（新手必讀）

因為程式內含 `fetch()` 非同步讀取資料機制，**請勿直接雙擊打開 `index.html`**（會因瀏覽器安全限制導致畫面空白或載入失敗），必須透過本機伺服器開啟。

### 第一步：下載專案
1. 進入 [GitHub 專案網頁](https://github.com/edithfxx/cheat-sheet)。
2. 點擊右上角綠色的「**Code**」按鈕，並選擇「**Download ZIP**」。
3. 下載後解壓縮，會得到一個專案資料夾。

### 第二步：使用 VSCode + Live Server 開啟
1. 開啟 [VSCode](https://code.visualstudio.com/) 編輯器。
2. 點擊選單的「檔案」→「**開啟資料夾**」，選擇剛剛解壓縮的專案資料夾。
3. 至 VSCode 左側的「擴充功能（Extensions）」市集，搜尋並安裝 **Live Server**。
4. 安裝完成後，在左側檔案列表的 `index.html` 上連按右鍵 → 選擇「**Open with Live Server**」。
5. 瀏覽器會自動彈出網頁，看見卡片畫面即代表成功 🎉。

> 💡 **提示**：第一次打開時，系統會自動載入內建的「操作說明」範例卡片，您可以先熟悉操作，之後再換成自己的內容。

## 📖 操作功能說明

| 功能 | 操作方式 |
|---|---|
| 🔍 **欄位搜尋** | 於上方搜尋框輸入關鍵字（支援標題、標籤、內容全域搜尋），亦可使用 `Ctrl + K` 快速聚焦。 |
| 📂 **切換分類** | 點擊上方分類標籤（如 HTML、CSS...）即可切換檢視。 |
| 🗃 **子分類篩選** | 點擊**右下角圓形浮動按鈕**，可進一步篩選當前分類下的子項目。 |
| 📋 **複製內容** | 點擊卡片右上角或特定行數右側的複製按鈕（純筆記 `note` 類型無複製功能）。 |
| 👁 **檢視詳情** | 卡片預設僅顯示部分內容，**點擊卡片任意處**即可彈出完整視窗，按 `Esc` 可關閉。 |
| ➕ **自訂卡片** | 點擊右上角「新增」按鈕，選擇卡片類型、填寫內容後儲存即可。 |
| ✏️ **編輯與刪除** | 點擊卡片上的**鉛筆圖示**進行修改，點擊**垃圾桶圖示**進行刪除。 |

## 💾 資料儲存與備份機制

- 本專案的卡片資料皆儲存於**您個人瀏覽器的 localStorage**（而非直接改動本機檔案）。
- 畫面的所有新增、修改、刪除皆會**自動即時儲存**，無須尋找儲存按鈕。

> ⚠️ **重要注意事項**：若您**清除瀏覽器快取、換瀏覽器、或更換電腦**，原先記錄的資料將會消失。請務必養定期備份的習慣！

### 備份與跨裝置同步流程

1. 點擊網頁右上角的**齒輪設定圖示** → 選擇「**匯出 data.json**」，將檔案下載至電腦。
2. 將該檔案移至專案資料夾中的 `data/update/` 目錄下，並**覆蓋**原有的 `data.json`。
3. 未來在其他電腦第一次開啟此專案時，網頁便會自動讀取該檔案作為初始資料。

> 💡 **強制覆蓋提示**：若在同一台已使用過的電腦上想強制同步最新的 `data.json` 內容，請點擊設定中的「**重置為 data.json**」（注意：此動作會清空目前瀏覽器中尚未匯出的所有變更）。

| 類型 | 適用場景 | 範例 |
|---|---|---|

## ❓ 常見問題（FAQ）

**Q：為什麼雙擊打開 `index.html` 是一片空白？**
A：由於網頁使用了非同步資料載入（Fetch API），受限於瀏覽器安全機制，必須透過 Live Server 等本機伺服器環境開啟，請參考「如何開始」章節。

**Q：我的自訂卡片突然都不見了？**
A：資料是暫存在瀏覽器中，若執行了清理瀏覽器隱私資料的動作將會被抹除。請由備份的 `data.json` 置入 `data/update/` 後，點擊設定內的「**重置為 data.json**」即可恢復。

**Q：我可以自行增加新的大分類嗎？**
A：可以。請用編輯器開啟 `script/config.js`，修改 `CATEGORIES` 陣列，直接在內部加上您想要的分類名稱字符串即可。

## 🛠 技術底層

- **Vue 3**（採用 CDN 全域版本，免去 npm 安裝與編譯打包流程）
- 原生 CSS 與 CSS 變數（CSS Variables）
- 資料儲存：瀏覽器 Web Storage (localStorage)
- 開發環境：VSCode + Live Server 擴充套件

> 本專案特意不引入 React、Vite 或 TypeScript 等繁瑣的打包工具，核心宗旨為「**一個資料夾，用瀏覽器打開即可部署與使用**」。
